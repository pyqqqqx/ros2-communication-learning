## 一、任务概述

本次任务完整走通一次 ROS2 通讯链路，覆盖以下四个环节：

1. **读队友发布**：接收队友（陈明丰）的 5 个发布节点数据；
2. **接收方计算**：订阅队友数据，按指定公式计算并发布结果；
3. **自定义接口**：定义自定义消息 `MyData.msg`；
4. **自己的发布**：参数化节点 + launch 一键启动 5 个发布节点。

---

## 二、交付内容

共 **5 个功能包**，位于仓库 `src/` 目录，也可通过 `ros2_task_deliver.tar.gz` 一键解压使用。

| 包名 | 类型 | 作用 |
|------|------|------|
| `data_publisher` | ament_python | 队友发布方，5 个节点向 `/node1`~`/node5` 发数据（5Hz） |
| `status_interfaces` | ament_cmake | 队友的消息接口 `Data.msg` |
| `data_subscriber` | ament_python | 接收计算：`calc1` / `calc2` / `final` 三个节点 |
| `my_interfaces` | ament_cmake | 自定义消息接口 `MyData.msg` |
| `my_publisher` | ament_python | 参数化发布节点 `my_pub_1~5` + launch |

### 消息定义

```text
builtin_interfaces/Time stamp      # 时间戳
float32[3] data_group              # 三维数组，分别记为 a、b、c
```

### 计算逻辑

| 节点 | 订阅 | 公式 | 输出话题 |
|------|------|------|----------|
| `calc1_node` | `/node1` `/node2` `/node3` | `(a1+a2+a3) - (b1+b2+b3) + (c1+c2+c3)` | `/calc1_result` |
| `calc2_node` | `/node4` `/node5` | `(a4+b4) * (a5-b5)` | `/calc2_result` |
| `final_node` | `/calc1_result` `/calc2_result` | 捕获并打印两路结果 | — |

结果类型统一使用 `std_msgs/Float32`。

---

## 三、通讯链路

```text
队友链：data_pub_1~5 ──► /node1~5 ──► calc1/calc2 ──► /calc1_result、/calc2_result ──► final_node
自己链：my_pub_1~5  ──► /pub1~5 (MyData, 5Hz)
```

## 四、复现步骤

> 环境：Ubuntu 22.04 + ROS2 Humble。

```bash
# 1. 放入工作空间
mkdir -p ~/ros2_ws/src
tar xzf ros2_task_deliver.tar.gz -C ~/ros2_ws/src

# 2. 编译
cd ~/ros2_ws
colcon build

# 3. 配置环境（每个新终端都要执行）
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash

# 4. 启动节点
ros2 launch data_publisher pub_launch.py   # 队友的 5 个发布节点
ros2 launch my_publisher pub_launch.py     # 自己的 5 个发布节点
ros2 run data_subscriber calc1_node
ros2 run data_subscriber calc2_node
ros2 run data_subscriber final_node

# 5. 验证
ros2 topic list
ros2 topic echo /pub1
ros2 topic echo /node1
ros2 topic echo /calc1_result
ros2 topic hz /pub1
```

## 六、本次修复说明

**问题**：`calc1_node.py`、`calc2_node.py`、`final_node.py`、`my_pub.py` 四个文件末尾的
守卫语句被写成了 `if __name__ == '__&#8203;main__':`，其中混入了字面量 `&#8203;`（零宽字符）。

- **现象**：直接 `python3 xxx.py` 运行不会进入 `main()`；
- **影响范围**：仅影响「脚本直接运行」。`ros2 run` / `ros2 launch` 走 `setup.py` 的
  `entry_points` 直接调用 `main()`，不受影响；
- **修复**：统一改为标准的 `if __name__ == '__main__':`；
- **状态**：已修复、重新打包，并推送至 GitHub（commit `d97566b`）。
